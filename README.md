# واجب مواطنة 🇸🇦🌴

مبادرة تعليمية تفاعلية لطلاب المرحلة الابتدائية في المملكة العربية السعودية:
تُغرّس حب الوطن والانتماء، وتعزّز الشعور بالأمان والطمأنينة، وتُعلّم الطفل دعم وطنَه
بسلوك مسؤول ووعي رقمي وعمل مجتمعي.

## 🔗 النشر الرسمي

الموقع منشور حاليًا عبر **GitHub Pages** على الرابط:

**https://razan-mohammed-tech.github.io/wajib-watania/**

المستودع: https://github.com/razan-mohammed-tech/wajib-watania

## المزايا

- واجهة عربية كاملة (RTL) متجاوبة مع الجوال والتابلت والكمبيوتر.
- ألوان الهوية: الأخضر السعودي + الأبيض + لمسات ذهبية.
- ١٣ موقفًا تفاعليًا (محاكي القرار الوطني) بتغذية راجعة فورية.
- ٦ تحديات وطنية قابلة للتنفيذ، يدور تحدي الأسبوع تلقائيًا كل أسبوع.
- سجل إنجاز بشارات ومستويات تقدّم.
- لوحة معلمة تعرض بيانات عرض تجريبية + إحصاء حقيقي للجهاز الحالي.
- **لا تسجيل دخول، ولا قاعدة بيانات، ولا جمع أي بيانات شخصية.**

## تشغيل الموقع محليًا

### الطريقة الأولى (موصى بها): خادم PowerShell مرفق

```powershell
cd "C:\Users\razan\Desktop\واجب مواطنة"
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8080
```

ثم افتح المتصفح على: <http://localhost:8080>

### البدائل

- خادم Node (إن كان مثبّتًا): `npx serve .`
- خادم بايثون (إن كان مثبّتًا): `python -m http.server 8080`

> ملاحظة: لا تفتح الملف `index.html` مباشرةً بروتوكول `file://` لأن متصفحات Chrome وEdge
> تمنع تحميل وحدات ES Modules من الملفات المحلية. استخدم خادمًا محليًا كما في الأعلى.

## النشر

الموقع ثابت بالكامل (HTML/CSS/JS) — يُنشر على أي استضافة ثابتة دون خطوة بناء:

1. **GitHub Pages**
   - ارفع مجلد المشروع إلى مستودع.
   - من إعدادات المستودع: Pages → Source: `main` / مجلد الجذر.
   - سيعمل الموقع مباشرة على `https://<اسمالمستودع>.github.io/`.
2. **Netlify**
   - اسحب مجلد المشروع إلى صفحة Netlify Drop.
   - لا حاجة لأي إعداد بناء (Build command فارغ، Publish directory = `.`).
3. **Vercel**
   - استورد المستودع واختر Framework: **Other** ثم انشر.
4. **أي استضافة مشتركة (cPanel / Hostinger)**
   - ارفع محتويات المجلد إلى `public_html` عبر FTP، ثم افتح النطاق.

## بنية المشروع

```
واجب مواطنة/
├── index.html              # الصفحة الوحيدة (SPA براوتر hash)
├── serve.ps1               # خادم محلي بسيط للتجربة
├── assets/
│   └── logo.png            # شعار المدرسة (يظهر في الترويسة + أيقونة المتصفح)
├── css/
│   ├── tokens.css          # متغيّرات التصميم (الألوان، الخطوط، الظلال)
│   └── app.css             # التنسيق العام + التجاوب
└── js/
    ├── main.js             # نقطة الدخول والراوتر
    ├── store.js            # حالة التقدّم (localStorage فقط)
    ├── data/               # ⬅ كل المحتوى هنا (منفصل عن الواجهة)
    │   ├── site.js         # نصوص الموقع والرؤية والأهداف
    │   ├── scenarios.js    # مواقف محاكي القرار (١٣)
    │   ├── challenges.js   # التحديات (٦) + اختيار تحدي الأسبوع
    │   ├── badges.js       # الشارات والمستويات
    │   └── teacher.js      # إعدادات المعلمة (الأسماء الافتراضية)
    ├── components/         # مكوّنات قابلة لإعادة الاستخدام
    │   ├── site-header.js
    │   ├── site-footer.js
    │   ├── toast.js        # التنبيهات + الاحتفال
    │   └── ui.js           # أدوات مساعدة (أشرطة تقدم، مخططات، أرقام عربية)
    └── pages/              # الصفحات الست
```

## إضافة محتوى جديد

- **تغيير الشعار:** استبدل ملف `assets/logo.png` بشعار أوضح (يفضّل خلفية شفافة وحجم أقل من ١٠٠٠×١٠٠٠ بكسل).
- **إضافة موقف:** أضف كائنًا في `js/data/scenarios.js` بنفس بنية المواقف الموجودة،
  وحدّد `correct: true` للخيار الصحيح فقط.
- **إضافة تحدٍّ:** أضف كائنًا في `js/data/challenges.js` (`id` فريد، و`steps` بين ٣ و٦ خطوات).
- **إضافة شارة:** أضف كائنًا في `js/data/badges.js` بدوال `test(state)`.

## إعدادات المعلمة

داخل «لوحة المعلمة» يوجد قسم **إعدادات المعلمة** يعرض ويسمح بتعديل:

- المعلمة المسؤولة عن المبادرة (الافتراضي: **رزان أبوهيله**)
- مديرة المدرسة (الافتراضي: **أمل كدسه**)
- اسم المدرسة (اختياري)

القواعد المطبّقة:

- تُحفظ هذه القيم في `localStorage` على الجهاز الذي عدّلها فقط، ولا تُرسل إلى أي خادم.
- تخصّ الكبار (المعلمة/المديرة) فقط، ولا تُجمع أي بيانات عن الأطفال إطلاقًا.
- زر «استعادة الافتراضي» يحذف التعديلات ويعيد الأسماء من `js/data/teacher.js`.

## ملاحظات الخصوصية

- لا يجمع الموقع أي اسم أو صورة أو موقع أو رقم هاتف.
- تقدّم الطفل يُحفظ في `localStorage` داخل متصفح جهازه فقط، ويمكن حذفه من
  «سجل الإنجاز» أو «لوحة المعلمة».
- لا تُرسل أي بيانات إلى أي خادم، ولا يوجد قاعدة بيانات.
- بيانات «لوحة المعلمة» الملوّنة هي بيانات عرض تجريبية مختلقة، ولست نتائج حقيقية.
